# Programmeerimise alused : E-poe loomine

## Laadimine ja käivitamine
1. klooni repositoorium `git clone https://github.com/kaareltiitt6nts/ylesanne-epood`
2. lae **Node v18.19.0**
3. lae projekti sõltuvused `npm install`
4. käivita käsurealt server `node server.js`
5. ava brauseris `127.0.0.1:3000`
